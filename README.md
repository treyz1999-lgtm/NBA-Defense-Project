# NBA Defense Analytics Project

## Overview

This project explores the relationship between regular-season team performance metrics and playoff success in the National Basketball Association (NBA). The goal is to identify which defensive and overall team metrics are most strongly associated with deep playoff runs and championship success.

## Project Workflow

1. **Data Collection**
   - Historical NBA team statistics and playoff results were collected using a custom Python web scraper.

2. **Data Preparation**
   - Raw data was cleaned, standardized, and organized for analysis.
   - Processed datasets were exported for further analysis.

3. **SQL Analysis**
   - SQL was used to clean, transform, and analyze the data.
   - Queries were written to investigate relationships between team performance metrics, playoff advancement, and championship outcomes.

4. **Data Visualization**
   - Query results were exported as CSV files and imported into Tableau.
   - Interactive dashboards were created to visualize trends, compare franchises, and highlight key findings.
